# Lab 1 — List Search

Лабораторная работа №1 по технологиям разработки мобильных приложений.

## Задание (вариант 1)

В списке найти индекс первого отрицательного и последнего положительного элементов.

Входные данные генерируются случайным образом (20 чисел в диапазоне [-50, 50]).

## Запуск

1. Открыть проект в Android Studio.
2. Запустить на эмуляторе или устройстве (minSdk 31).
3. Нажать **Найти**, чтобы получить результат. Кнопка **Перегенерировать** создаёт новый список.
