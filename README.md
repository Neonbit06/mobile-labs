# Musician's Diary

Лабораторная работа №3 по технологиям разработки мобильных приложений.

## Описание приложения

«Musician's Diary» — это приложение-дневник для композиторов, музыкантов и продюсеров. Позволяет вести учёт своих творческих идей, композиций и репетиций.

## Функционал

- Создание, редактирование и удаление записей.
- Хранение данных в локальной базе данных SQLite (Room).
- Сортировка записей по дате.
- Указание типа записи (Композиция, Репетиция, Идея, Прочее).
- Указание темпа (BPM) и тональности.
- Просмотр деталей записи и полного текста заметки.

## Технологии

- Язык: Kotlin
- UI: Jetpack Compose (Material 3)
- Архитектура: MVVM (ViewModel + StateFlow)
- База данных: Room (SQLite)
- Навигация: Navigation Compose

## Запуск

1. Открыть проект в Android Studio.
2. Запустить на эмуляторе или устройстве (minSdk 31).
3. Нажать на кнопку **«+»** в правом нижнем углу для создания первой записи.
